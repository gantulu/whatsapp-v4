## Official Documentation

Use the following Meta resources as the technical references for WhatsApp Cloud API development:

1. **Meta WhatsApp Business Platform — Postman Overview**  
   https://www.postman.com/meta/whatsapp-business-platform/overview

2. **WhatsApp Cloud API — Postman Collection**  
   https://www.postman.com/meta/whatsapp-business-platform/collection/wlk6lh4/whatsapp-cloud-api

3. **Meta Developers — WhatsApp Cloud API**  
   https://developers.facebook.com/docs/whatsapp/cloud-api

The Meta Developers documentation is the primary source of truth for supported API behavior, endpoints, authentication, requests, responses, and webhooks. The Postman resources provide the official API collection and request examples.
